# Fahrplan

გერმანიის საზოგადოებრივი ტრანსპორტის რუკა. საიტის ფაილები თავსებადია GitHub Pages-თან.

## მონაცემები

- გაჩერებები და ძიება მოდის [Transitous-იდან](https://transitous.org/sources/).
- რუკის გვერდით სია შეიცავს რეისებს, რომელთათვისაც MOTIS მიმდინარე განახლებას აბრუნებს. გაჩერების ტაბლო აჩვენებს ლაივ დროს, დაგვიანებას, გაუქმებას, გამოტოვებულ გაჩერებას, შეცვლილ ბაქანსა და შეტყობინებებს, თუ წყარო მათ აქვეყნებს.
- რეისზე დაჭერისას იხსნება მარშრუტის რუკა და გაჩერებები. ხაზის გეომეტრია MOTIS-ის მიერ დაბრუნებული მარშრუტია. დროებითი შემოვლის ხაზი ჩანს მხოლოდ მაშინ, როცა წყარო ახალ გეომეტრიას აბრუნებს.
- ღია გვერდი მონაცემებს 30 წამში ერთხელ ამოწმებს. შეამოწმეთ [Transitous-ის გამოყენების პირობები](https://transitous.org/api/) საჯარო გამოყენებამდე. მათი საერთო სერვისი განკუთვნილია ღია კოდის არაკომერციული პროექტებისთვის.

## მანქანის მდებარეობის წყაროს დაკავშირება

[Transitous](https://transitous.org/doc/) აქ გამოყენებულ პასუხებში გაზომილ კოორდინატებს არ აბრუნებს. რუკა განახლებული მოსვლისა და გასვლის დროებიდან მარშრუტზე მდებარეობას გამოთვლის. მარკერზე ნიშანი ≈ გამოთვლილ პოზიციას აღნიშნავს. ახალი გაზომილი კოორდინატი გამოთვლილ პოზიციას ცვლის. ტაბლოს ტაიმერი მოსვლის პროგნოზს წუთებითა და წამებით აჩვენებს. პოზიციების დასაკავშირებლად:

1. ოპერატორის პოზიციების ნაკადი (მაგ. GTFS-RT VehiclePositions) წაიკითხეთ ცალკე სერვერზე. შეუთავსეთ რეისის იდენტიფიკატორი MOTIS-ის სრულ `tripId`-ს, მომსახურების დღის და წყაროს გათვალისწინებით. თითოეული ოპერატორის მონაცემთა დაფარვა ცალკე შეამოწმეთ.
2. სერვერის მისამართი ჩაწერეთ `index.html`-ში, `VEHICLE_POSITIONS_URL`-ში. სერვერი უნდა იღებდეს `min=lat,lon&max=lat,lon` პარამეტრებს და GitHub Pages-ის დომენს უშვებდეს CORS-ით. გასაღებები შეინახეთ სერვერზე.
3. პასუხის ფორმატია `{"vehicles":[{"tripId":"<MOTIS tripId>","lat":52.52,"lon":13.41,"timestamp":"<ISO 8601 observation time>"}]}`. გამოიყენეთ დაკვირვების დრო. წყაროს შეუძლია დაამატოს `stopId` და `stopped`, თუ ადგილისა და გაჩერებაზე დგომის სტატუსი გაზომილია. 90 წამზე ძველი გაზომვა იცვლება გამოთვლილი პოზიციით, როცა შესაბამისი მონაცემები არსებობს. პოზიციის გამოსაჩენად რეისი მიმდინარე MOTIS სიაში უნდა იყოს.

## ფაილების განახლება

`index.html` და `live-transit.js` განათავსეთ რეპოზიტორიის ძირში, ერთ საქაღალდეში. `README.md` შეიცავს მონაცემთა წყაროების აღწერას.
