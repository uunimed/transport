# Fahrplan

გერმანიის საზოგადოებრივი ტრანსპორტის რუკა. საიტის ფაილები თავსებადია GitHub Pages-თან.

## მონაცემები

- გაჩერებები და ძიება მოდის [Transitous-იდან](https://transitous.org/sources/).
- რუკის მარკერები იყენებს Transitous/MOTIS-ის განახლებულ გაჩერების დროებსა და მარშრუტის გეომეტრიას. როცა პოზიცია გამოთვლილია, მარკერს, კოორდინატებსა და სიჩქარეს აქვს ნიშანი `≈`. ტაბლოზე დადასტურებული მოსვლა ოპერატორის დაფიქსირებულ მოვლენას ეყრდნობა.
- Chemnitz-ისა და საქსონიის რამდენიმე ქალაქისთვის VVO/VMS-ის გასვლები სარეზერვო ტაბლოა, როცა Transitous მიმდინარე მონაცემს ვერ აბრუნებს და გაჩერების იდენტიფიკატორი ზუსტად ემთხვევა.
- გერმანიის რუკის ნიღაბი იყენებს [Natural Earth-ის](https://www.naturalearthdata.com/) 1:50m საზღვრებს.
- რეისზე დაჭერისას იხსნება მარშრუტის რუკა და გაჩერებები. ხაზის გეომეტრია MOTIS-ის მიერ დაბრუნებული მარშრუტია. დროებითი შემოვლის ხაზი ჩანს მხოლოდ მაშინ, როცა წყარო ახალ გეომეტრიას აბრუნებს.
- ღია გვერდი მონაცემებს 30 წამში ერთხელ ამოწმებს. შეამოწმეთ [Transitous-ის გამოყენების პირობები](https://transitous.org/api/) საჯარო გამოყენებამდე. მათი საერთო სერვისი განკუთვნილია ღია კოდის არაკომერციული პროექტებისთვის.

## მანქანის მდებარეობის წყაროს დაკავშირება

[Transitous](https://transitous.org/doc/) აქ გამოყენებულ პასუხებში გაზომილ კოორდინატებს არ აბრუნებს. გაზომილი პოზიცია, როცა ხელმისაწვდომია, გამოთვლილ პოზიციას ცვლის. პოზიციების დასაკავშირებლად:

1. ოპერატორის პოზიციების ნაკადი (მაგ. GTFS-RT VehiclePositions) წაიკითხეთ ცალკე სერვერზე. შეუთავსეთ რეისის იდენტიფიკატორი MOTIS-ის სრულ `tripId`-ს, მომსახურების დღის და წყაროს გათვალისწინებით. თითოეული ოპერატორის მონაცემთა დაფარვა ცალკე შეამოწმეთ.
2. სერვერის მისამართი ჩაწერეთ `index.html`-ში, `VEHICLE_POSITIONS_URL`-ში. სერვერი უნდა იღებდეს `min=lat,lon&max=lat,lon` პარამეტრებს და GitHub Pages-ის დომენს უშვებდეს CORS-ით. გასაღებები შეინახეთ სერვერზე.
3. პასუხის ფორმატია `{"vehicles":[{"tripId":"<MOTIS tripId>","lat":52.52,"lon":13.41,"timestamp":"<ISO 8601 observation time>"}]}`. გამოიყენეთ დაკვირვების დრო. წყაროს შეუძლია დაამატოს `stopId` და `stopped`, თუ ადგილისა და გაჩერებაზე დგომის სტატუსი გაზომილია. 90 წამზე ძველი პოზიცია ქრება. პოზიციის გამოსაჩენად რეისი მიმდინარე MOTIS სიაში უნდა იყოს.

## ფაილების განახლება

`index.html` შეიცავს აპლიკაციის სრულ კოდს, დაგეგმვისა და რუკის მოდულების ჩათვლით. გარე ბიბლიოთეკებისა და რეალური დროის მონაცემებისთვის საჭიროა ინტერნეტთან წვდომა.
